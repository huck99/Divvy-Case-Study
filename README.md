# Divvy Bike Sharing Case Study (Tableau Dashboard)

This project is a Tableau-based data visualization case study using Divvy bike-share data. It analyzes customer behavior, ride duration, trip frequency, and usage patterns to uncover actionable insights.

## 🚲 Project Overview

- **Objective:** Analyze Divvy bike-sharing data to understand usage trends and differences between member and casual users.
- **Focus Areas:** Ride behavior by day/time, rideable types, popular stations, and seasonal usage patterns.

## 📊 Key Insights

- Casual users ride more on weekends and during the afternoon, while members ride consistently across weekdays.
- Casual users have significantly longer average ride durations.
- Summer months show the highest overall usage; winter months experience a steep decline.
- Some stations are clearly preferred by casual riders, indicating tourist-heavy areas.
- most of the rides starts from the city centre
- riders prefer the classic bikes to docked bikes and electric bikes
- none of the members prefer to ride docked bikes

## 🧰 Tools Used

- **Tableau Desktop** – Interactive dashboard creation and visualization
